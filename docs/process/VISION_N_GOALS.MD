# Vision and Goals

## Vision

Meta Cost Center should give hackathon participants confidence and control over their Meta API costs, so they can experiment freely without unpleasant cost surprises.

## Goals

1. Determine how far Meta Cost Center can be ported to macOS arm64.
2. Ask ExamPro/Andrew for help where the port requires project-owner knowledge or decisions.
3. Ask other participants in the ExamPro hackathon Discord group for help when useful.
4. Announce the work early so other participants do not duplicate the same effort.
